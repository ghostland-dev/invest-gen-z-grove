# Invest Gen Z

Investment education site for young investors.

## Features

- Articles and categories
- Tools and dashboard
- Newsletter

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/invest-gen-z-grove.git
cd invest-gen-z-grove
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
